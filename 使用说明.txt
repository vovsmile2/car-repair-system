📦 安装说明
══════════════════════════════════════════════════════════════════

1️⃣  安装 Node.js（如果尚未安装）
   • 访问：https://nodejs.org/
   • 下载并安装 LTS 版本（推荐 18.x 或 20.x）
   • 安装完成后重启电脑

2️⃣  启动系统
   • 双击"启动.bat"文件
   • 首次运行可能需要几秒钟启动
   • 看到"汽车维修管理系统已启动"提示即表示成功

3️⃣  打开浏览器
   • 在浏览器地址栏输入：http://localhost:3000
   • 开始使用系统！

🔧 常见问题
══════════════════════════════════════════════════════════════════

❓ 端口3000被占用怎么办？
   1. 右键点击"启动.bat"，选择"编辑"
   2. 找到 server-simple.js 文件
   3. 用记事本打开，修改最后一行的端口号：
      server.listen(3001, () => { ... });
   4. 保存后重新启动

❓ 如何修改已有记录？
   • 直接用记事本打开 data 目录下的 JSON 文件
   • 找到对应记录进行编辑
   • 保存文件即可

❓ 可以拷贝到其他电脑使用吗？
   • 可以！整个文件夹是可移植的
   • 拷贝后只需要确保安装了 Node.js
   • 双击"启动.bat"即可运行

❓ 支持多台电脑访问吗？
   • 不支持。这是单机版系统，只能本机访问
   • 如果需要多人使用，需要部署到服务器

❓ 为什么打开网页显示"无法访问"？
   1. 检查"启动.bat"的窗口是否还在运行
   2. 确认端口没有冲突
   3. 尝试关闭防火墙或添加例外规则
