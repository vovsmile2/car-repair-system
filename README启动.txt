========================================
  启动指南 - 启动乱码问题解决方案
========================================

如果遇到启动脚本乱码问题，请使用以下方法启动系统：

========================================
方法 1：使用 launch.bat（推荐）
========================================

双击文件：launch.bat

特点：
- 纯英文界面
- 完全避免编码问题
- 100% 兼容所有 Windows 系统

========================================
方法 2：使用 PowerShell 脚本
========================================

双击文件：run.ps1.bat

特点：
- 使用 PowerShell 运行
- 支持中文显示（蓝色界面）
- 颜色高亮，更易读
- 适合喜欢 PowerShell 的用户

========================================
方法 3：直接用命令行
========================================

1. 打开命令提示符（CMD）
   - 按 Win+R，输入 cmd，回车

2. 进入系统目录：
   cd D:\car-repair-system

3. 启动系统：
   node server-simple.js

========================================
启动后操作
========================================

1. 打开浏览器
   Chrome、Edge、Firefox 等

2. 访问地址：
   http://localhost:3000

3. 开始使用系统

========================================
停止系统
========================================

在启动窗口中按 Ctrl+C
或直接关闭窗口

========================================
故障排除
========================================

问题：双击 launch.bat 后窗口闪退

解决：
1. 打开 CMD
2. 输入：node -v
3. 如果显示错误，说明未安装 Node.js
4. 访问 https://nodejs.org/ 下载安装

问题：浏览器无法访问 localhost:3000

解决：
1. 检查启动窗口是否还在运行
2. 确认没有其他程序占用 3000 端口
3. 尝试关闭防火墙测试
4. 尝试用 127.0.0.1:3000

问题：PowerShell 脚本无法运行

解决：
1. 右键点击 run.ps1.bat
2. 选择"以管理员身份运行"
3. 或直接使用 launch.bat

========================================
启动文件对比
========================================

launch.bat         - 英文批处理（最稳定，推荐）
run.ps1.bat        - PowerShell 启动器（彩色中文）
start.bat          - 英文批处理（备用）
start.ps1          - PowerShell 脚本（手动运行）
启动.bat           - 中文批处理（可能有编码问题）
启动中文.bat       - 中文批处理（可能有编码问题）

推荐优先级：
1. launch.bat
2. run.ps1.bat
3. start.bat

========================================
系统要求
========================================

必需：Node.js（LTS 18.x 或 20.x）
下载：https://nodejs.org/

检查是否已安装（在 CMD 中）：
  node -v
