🚗 汽车维修管理系统 - Windows 版
==================================

欢迎使用汽车维修管理系统！这是一个简单易用的维修记录管理系统。

📦 快速开始
==========

1. 安装 Node.js（如果尚未安装）
   - 访问 https://nodejs.org/
   - 下载并安装 LTS 版本

2. 启动系统
   - 双击"启动.bat"文件
   - 看到"汽车维修管理系统已启动"提示即表示成功

3. 打开浏览器
   - 在浏览器地址栏输入：http://localhost:3000
   - 开始使用！

✨ 系统功能
==========

✓ 添加车辆信息 - 记录车牌、车型、车主信息
✓ 添加维修记录 - 记录维修部位、内容、费用
✓ 查询记录 - 按车牌号、日期查询维修历史
✓ 收入统计 - 按月统计维修收入

📁 文件说明
==========

启动.bat              - 双击此文件启动系统
server-simple.js       - 服务器程序
public/                - 网页界面文件
data/                  - 数据存储目录
  ├─ 车辆信息.json     - 车辆数据
  └─ 维修记录.json     - 维修记录

💾 数据备份
==========

⚠️  重要：所有数据保存在 data 目录中
   • 建议定期备份 data 目录
   • 复制整个 data 文件夹即可备份

🔧 常见问题
==========

Q: 端口3000被占用怎么办？
A: 编辑 server-simple.js，修改最后一行的端口号为 3001 或其他

Q: 如何修改已有记录？
A: 用记事本打开 data 目录下的 JSON 文件进行编辑

Q: 可以拷贝到其他电脑使用吗？
A: 可以！整个文件夹使用相对路径，可拷贝到任意电脑运行

Q: 支持多台电脑访问吗？
A: 不支持。这是单机版系统，只能本机访问

🛑 停止系统
==========

在命令窗口中按 Ctrl + C，或直接关闭窗口。

更多信息请查看"使用说明.txt"文件。
