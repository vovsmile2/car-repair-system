【问题描述】

查询时仍然报错：
  "查询失败：Unexpected token 'A', "API not found" is not valid JSON"

【问题原因】

服务器使用严格匹配 `url === '/api/records'`
但查询时的实际 URL 是：`/api/records?plate=xxx&fuzzy=true`
带有查询参数的 URL 无法匹配到路由，导致返回 "API not found"
浏览器尝试解析非 JSON 响应时报错

【解决方案】

✅ 修复了路由匹配逻辑
  从：url === '/api/records'
  改为：url.startsWith('/api/records')

✅ 改进了错误信息
  服务器返回 JSON 格式的错误信息
  包含 URL 和 method 信息，便于调试

✅ 添加了请求日志
  在服务器启动窗口显示所有 API 请求
