# 🚗 汽车维修管理系统 - Windows 版

一个简单易用的汽车维修记录管理系统，无需数据库，所有数据存储在本地JSON文件中，无需安装任何依赖。

## ✨ 特点

- ✅ **零配置** - 无需安装数据库，开箱即用
- ✅ **零依赖** - 无需 npm install，纯 Node.js 实现
- ✅ **可移植** - 使用相对路径，可拷贝到任意电脑运行
- ✅ **数据透明** - 数据以 JSON 格式存储，易于备份和迁移

## 📋 功能

- 📝 添加车辆信息（车牌、车型、车主等）
- 🔧 添加维修记录（维修部位、内容、费用）
- 🔍 查询记录（按车牌号、日期查询）
- 📊 收入统计（按月统计维修收入）

## 🚀 快速开始

### 1. 安装 Node.js

访问 [nodejs.org](https://nodejs.org/) 下载并安装 LTS 版本（推荐 18.x 或 20.x）。

### 2. 启动系统

双击 `启动.bat` 文件，或在命令行中运行：

```bash
node server-simple.js
```

### 3. 打开浏览器

在浏览器地址栏输入：`http://localhost:3000`

## 📁 文件结构

```
car-repair-system/
```

- 方法2：复制 JSON 文件到其他位置

## 🔧 常见问题

### 端口被占用？

编辑 `server-simple.js`，修改最后一行的端口号：

```javascript
server.listen(3001, () => { ... });
```

### 如何修改已有记录？

直接用文本编辑器打开 `data` 目录下的 JSON 文件进行编辑。

### 可以拷贝到其他电脑吗？

可以！整个文件夹使用相对路径，可拷贝到任意安装了 Node.js 的电脑上运行。

## 🛑 停止系统

在命令窗口中按 `Ctrl + C`，或直接关闭窗口。

## 📝 技术栈

- **后端**: Node.js (纯 HTTP，无 Express)
- **前端**: 原生 HTML/CSS/JavaScript
- **数据存储**: JSON 文件
